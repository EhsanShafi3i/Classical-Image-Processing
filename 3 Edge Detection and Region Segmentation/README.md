# تمرین ۳ — تشخیص لبه و بخش‌بندی نواحی

نوت‌بوک `solution.ipynb` از ابتدا بازسازی شده است. صورت تمرین از صفحهٔ ۳ فایل `Project1.pdf` و تعاریف ارزیابی از صفحات ۵ و ۶ پیاده‌سازی شده‌اند.

- تشخیص لبه: Sobel، Prewitt، Laplacian و LoG؛ بررسی هموارسازی، اندازهٔ هسته و آستانه؛ نازک‌سازی لبه و گزارش ODS/AP مطابق تنظیمات PDF.
- بخش‌بندی: Otsu، آستانه‌گذاری تطبیقی (میانگین و گاوسی) و K-means؛ بررسی پارامترها و گزارش Segmentation Covering و PRI.
- همهٔ شش تصویر و همهٔ annotationهای انسانی وارد ارزیابی می‌شوند؛ سه تصویر برای نمایش دیداری انتخاب می‌شود.
- نتایج و نمودارها در `outputs/` ذخیره می‌شوند.

نوت‌بوک را از پوشهٔ پروژه یا همین پوشه باز کنید و سلول‌ها را به ترتیب اجرا کنید. نیازمندی‌ها: `numpy`, `opencv-python`, `matplotlib`, `pandas`, `scipy`.
